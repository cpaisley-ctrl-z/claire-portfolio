# claire-portfolio

Claire's UX design portfolio, built with [React](https://react.dev) and [Vite](https://vite.dev).

## Getting started

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Scripts

| Command           | What it does                              |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Start the dev server with hot reload      |
| `npm run build`   | Build the production site into `dist/`    |
| `npm run preview` | Serve the production build locally        |
| `npm run lint`    | Lint the source with oxlint               |

## Project structure

```
index.html        Page shell and metadata
public/           Static files served as-is (favicon, images)
src/main.jsx      App entry point
src/App.jsx       Page layout and sections
src/App.css       Layout styles
src/index.css     Global styles and color tokens
```
